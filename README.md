# X 粉丝数量 · Chrome 插件

在 X 首页推文、评论作者和用户列表中，把粉丝数量显示在昵称和认证标志旁，采用截图中的浅蓝色标签。

## 安装（无需编译）

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，下载并解压源码。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后直接包含 `manifest.json` 的插件文件夹（通常名为 `x-follower-count-main`）。
5. 刷新已打开的 X 页面，在首页、评论或粉丝、认证粉丝、关注列表查看标签。

也支持 Chromium Edge。Chrome 最低版本 111。当前为本地加载版，未发布到 Chrome 网上应用店。

## 使用

- 默认显示：`粉丝 7`、`粉丝 7,806`、`粉丝 3.5万`。
- 大于等于 1 万使用“万”，大于等于 1 亿使用“亿”，保留一位小数并截断。
- 鼠标悬停在标签上，可以查看完整数字。
- 点击工具栏的插件图标，可以关闭标签或切换完整数字；设置即时应用到已加载插件的 X 页面。
- v1.0.2 弹窗底部会显示页面脚本、数据桥接、用户行、推文作者、已读取数量和已显示标签的状态，便于排查无显示问题。
- 适用于 X 使用 `UserCell` 的粉丝、认证粉丝、关注、用户搜索、推荐关注等列表，以及使用 `User-Name` 的首页推文、评论、推文详情作者标题。
- **显示的是该用户的总粉丝数**，不是其认证粉丝数，也不是你们的共同粉丝数。

## 数据与隐私

被动读取当前页面已经请求到的用户 JSON，不需要 API Key、不需要额外登录，也不会额外请求 X 接口。
兼容旧的 `legacy.followers_count` 和当前的 `relationship_counts.followers` 数据结构。
不读取 Cookie、认证令牌或密码，不上传任何数据，不关注/取关/发布推文。
只在内存中保留当前页面最近 2000 个账号的账号名和计数；刷新后清空。
`storage` 权限仅用于保存开关与显示方式，网站范围仅为 X / Twitter。

## 没有显示时

首先刷新 X 页面，让插件在页面发起请求之前开始观察。插件不会补发请求：若 X 没有提供某个用户的数量，该行暂不显示标签，绝不会用 0 代替未知值。
升级时请在 `chrome://extensions` 点击本插件的重新加载，然后刷新 X；若此前加载的是自行解压的另一份目录，需要用新版文件替换那份目录再重新加载。
数字是本次加载时的快照，更新数据可刷新页面。个人资料页原生粉丝数不属于本版新增标签的范围。
X 更新页面结构或响应字段后，可能需要适配插件。

## 开发与验证

无依赖、无构建步骤，Manifest V3；直接修改文件后在扩展管理页点击重新加载，再刷新 X。
双世界的静态脚本注入使用 Chrome 的 [content_scripts 官方配置](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)。

```bash
cd x-follower-count
node --test tests/*.test.cjs
```

DOM 回归（需要 ego-browser）：在另一个终端启动下面的本地测试服务器，再运行测试。

```bash
python3 -m http.server 8769 --bind 127.0.0.1
```

```bash
ego-browser nodejs < tests/browser-smoke.js
```

真实登录页面的验证截图与记录不包含在公开仓库中。
